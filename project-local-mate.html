01 / PROBLEM

혼자라는 건
위험할 수 있다.

지방 1인가구의 고립과 응급상황을 하나의 문제로 바라보고, “신호를 발견했을 때 실제 도움까지 얼마나 빠르게 연결할 수 있는가”에 집중했습니다.

$ USER
지역에 혼자 사는 20–80대

$ PAIN
고립 / 응급 / 도움 요청의 공백

$ QUESTION
가장 가까운 도움을 어떻게 연결할까?
02 / 01 — DETECT

작은 신호를
발견한다.

웨어러블과 생활 데이터를 통해 평소와 다른 상태를 확인하고, 위험 가능성을 먼저 포착합니다.

02 / 02 — DECIDE

위험도를
판단한다.

관찰 · 주의 · 응급 단계로 구분해 과도한 개입은 줄이고, 정말 필요한 순간에는 즉시 대응합니다.

02 / 03 — CONNECT

가장 가까운
도움을 부른다.

지역메이트, 보호자, 기관, 이동수단까지 상황에 맞는 자원을 순서대로 연결합니다.

02 / 04 — CARE

응급 이후에도
이어진다.

한 번의 구조가 끝이 아니라, 평소의 안부와 생활 지원까지 연결되는 지역 케어 네트워크를 만듭니다.
